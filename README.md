# Анализ данных розничного магазина с помощью PySpark

## 📋 О проекте
Проект представляет собой полный цикл обработки и разведочного анализа данных (EDA) для датасета `retail_store_sales.csv` с использованием PySpark. Включает загрузку, очистку пропусков, генерацию признаков и аналитику.

## 🛠️ Технологии
- Python 3.12
- Apache Spark (PySpark)
- Java 17 (OpenJDK)
- Git / GitHub

## 📂 Структура проекта
- `retail_store_sales.csv` — исходные данные
- `retail_store.py` — основной скрипт с анализом
- `README.md` — документация

## 🚀 Как запустить
1. Установите Java 17 и настройте переменную среды `JAVA_HOME`.
2. Установите PySpark: `pip install pyspark`.
3. Поместите файл `retail_store_sales.csv` в корень проекта.
4. Запустите скрипт: `python retail_store.py`.

## 🔍 Этапы работы
1. **Загрузка и подготовка**: Приведение названий колонок к `snake_case`, типизация данных (`integer`, `double`, `date`, `boolean`), обработка некорректных значений.
2. **Очистка и валидация**: Восстановление пропущенных `item` через справочник, расчет `total_spent`, `quantity` и `price_per_unit`, удаление невосстановимых строк.
3. **Разведочный анализ (EDA)**: Топ-5 категорий по продажам, расчет среднего чека по способам оплаты и локациям.
4. **Генерация признаков**: Выделение дня недели и месяца, анализ продаж по времени, расчет CLV (Customer Lifetime Value) и вывод топ-10 клиентов.

## 💡 Ключевые выводы
- Пик среднего чека приходится на декабрь и январь, а также на пятницу и воскресенье.
- Клиентская база (25 человек) демонстрирует высокую и равномерную активность.
